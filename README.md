# Digital Portfolio
This digital portfolio was created to give basic information about myself and display my current and past experiences and projects.

Run `npm ci` to install dependencies, `npm run dev` to start the development
server, and `npm run build` to create a production build.

Vite 7 requires Node.js 20.19+ or 22.12+. This project includes Node 22 as a
development dependency so npm scripts use a compatible runtime automatically.
CI also uses Node 22. Updating your system Node to Node 22 avoids engine warnings
when running npm install or npm audit fix.
